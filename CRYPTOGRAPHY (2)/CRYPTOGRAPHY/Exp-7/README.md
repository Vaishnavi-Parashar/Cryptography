## 1. Aim

To develop Python programs for implementing RSA encryption and Diffie–Hellman key exchange in Visual Studio Code and understand their applications in public-key cryptography.

## 2. Software Requirements

- Python 3
- Visual Studio Code (VS Code)

## 3. Theory

### A. RSA (Rivest–Shamir–Adleman) Algorithm

RSA is a public-key encryption technique that works with two mathematically connected keys. It uses a public key to encrypt information and a private key to recover the original data.

The algorithm relies on mathematical calculations involving prime numbers, modular arithmetic, and Euler's totient function. Its security is based on the difficulty of factoring large numbers into their prime factors.

### B. Diffie–Hellman Key Exchange

Diffie–Hellman is a cryptographic method that enables two users to establish a common secret key over a public communication channel.

In this technique, both participants select their own private values and calculate corresponding public values. By exchanging these public values and performing modular exponentiation, both parties independently generate an identical shared secret without directly sending that secret to each other.

## 5. Implementation Procedure

### Part A: RSA Algorithm

1. Launch Visual Studio Code and open the `RSA.py` program.
2. Initialize two prime numbers by assigning the values \(p=61\) and \(q=53\).
3. Calculate the modulus \(n\) by multiplying both prime numbers and determine Euler's totient value \(\phi(n)\).
4. Select the public exponent and calculate the corresponding private exponent using the modular multiplicative inverse.
5. Provide a numerical message as plaintext, ensuring that its value is smaller than \(n\).
6. Apply the RSA encryption formula using the public key to obtain the ciphertext.
7. Perform decryption with the private key to retrieve the original numerical message.
8. Compare the decrypted value with the initial plaintext to confirm the correctness of the operation.

### Part B: Diffie–Hellman Algorithm

1. Open the `DiffieHellman.py` source file in Visual Studio Code.
2. Initialize the public prime number as \(p=23\) and the generator as \(g=5\).
3. Assign separate private values to the two participants, Alice and Bob.
4. Generate Alice's and Bob's public keys using modular exponentiation.
5. Exchange the calculated public values between the two participants.
6. Use their respective private keys and the received public values to independently calculate the shared secret.
7. Compare the final secret values generated by both participants.
8. If the calculated values are identical, the key exchange is considered successful.
