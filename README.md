# Cryptography and Network Security – Practical Experiments

Welcome to my **Cryptography and Network Security** practical repository. This repository contains the implementations, experiments, code, and practical work completed as part of the Cryptography and Network Security course.

The experiments cover classical encryption techniques, modern cryptographic algorithms, hashing, digital signatures, network security, password auditing, and secure communication.

## Faculty Guidance

All the experiments included in this repository were performed under the valuable guidance of:

**Mr. Hirendra Singh Sengar**

## Technologies and Tools Used

- Python
- Visual Studio Code
- CrypTool
- OpenSSL
- Wireshark
- Kali Linux
- John the Ripper

## Learning Outcomes

Through these practical experiments, I gained hands-on experience in:

- Understanding classical and modern encryption techniques.
- Implementing symmetric and asymmetric cryptographic algorithms.
- Generating cryptographic hashes and verifying digital signatures.
- Working with RSA keys and digital certificates.
- Understanding secure key exchange using Diffie–Hellman.
- Implementing password hashing and salting techniques.
- Capturing and analyzing network traffic using Wireshark.
- Understanding TLS, HTTPS, and VPN security.
- Performing password security auditing.
- Configuring SSH-based authentication between Linux systems.
